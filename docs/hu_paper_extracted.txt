摘
要
随着互联网技术的持续进步，Web 应用在各行业被广泛应用，同时许多网络应用
都需要与后端数据库进行联系，这使得数据库成为攻击的目标。其中，SQL（Structured
Query Language）注入攻击尤为常见，攻击者通过在Web 请求中插入恶意SQL 代码，导
致这些代码被代入到数据库执行，可能会引起信息泄露、网页篡改等问题。传统的安全
措施，如输入验证和规则匹配，往往无法有效检测这些攻击，因为攻击者采用了多种
混淆绕过技巧来混淆恶意的SQL 载荷。本研究针对SQL 注入攻击检测提出了一种基于
AST-LSTM 的SQL 注入入侵检测的方法。
（1）针对如何精确检测Web 服务端的SQL 注入攻击问题，传统方法多用规则匹配，
但是过度依赖人工经验以及需要不断更新规则库。本文提出了一种基于AST-LSTM 的
SQL 注入入侵检测的方法，首先，本文重点分析了Web 应用程序的HTTP 请求，提取
出HTTP 请求中可注入的部分，如URL 和Cookie 部分，并将它们拼接起来形成完整的
文本序列，以进行进一步的分析。在此之后对文本序列进行规范化处理，以减轻攻击者
混淆技术的影响。此外，为了解决现有研究在SQL 查询语句细粒度检测方面的局限性，
本文首先对规范化后的SQL 语句进行词法和语法分析，生成抽象语法树（AST）。根据
抽象语法树的分层结构，提取出结构特征和语义特征进行分析，利用LSTM 深度学习模
型对抽象语法树生成的序列进行训练。本文同时还构建Tree-LSTM 模型用于SQL 注入
入侵检测对其进行评估与本文实验进行对比。
（2）针对如何提升SQL 注入攻击检测模型鲁棒性问题，传统方法利用网络上现有
数据集进行深度学习训练，然而随着攻击者混淆行为的不断升级，现有数据集无法涵盖
大部分的攻击行为。本文探索了利用强化学习技术生成对抗样本来增强SQL 注入攻击
检测模型的鲁棒性这一方法。通过研究SQL 注入攻击对模型的影响，利用预定义的混
淆策略，将混淆策略相互组合生成可以绕过SQL 注入攻击检测模型的对抗样本，使得
模型错误预测此类恶意样本。本文提出了一种基于强化学习的方法来生成对抗样本。通
过将不断混淆的样本与目标检测模型进行对抗，生成强混淆的对抗样本。这些对抗样本
用于对检测模型进行对抗性训练，以提高其对复杂攻击技术的抵抗力。
（3）为了促进实际实施，本文设计了一种基于AST-LSTM 的SQL 注入入侵检测系
统。该系统旨在在Web 服务器和数据库层面检测SQL 注入攻击。本文在控制环境中进
行实验，设置了模拟攻击场景，并使用数据包捕获工具捕获流量数据。此外，本文利用
搜索和分析引擎来存储和分析流量数据，并使用可视化界面来显示详细的流量信息和入
侵检测结果。通过广泛的实验和评估，本文证明了所提出的SQL 注入攻击检测方法的
有效性和鲁棒性，突显了其在增强Web 应用程序和数据库安全性的潜力。
关键词：SQL 注入，抽象语法树，深度学习，强化学习，入侵检测系统

Abstract
With the continuous advancement of internet technology, Web applications are extensively
employed across various industries, and many online applications need to interact with backend
databases, making these databases targets for attacks. Among these, SQL (Structured Query
Language) injection attacks are particularly common, where attackers insert malicious SQL
code into Web requests, causing these codes to be executed in databases, potentially leading
to information leakage and webpage tampering. Traditional security measures, such as input
validation and rule matching, often fail to effectively detect these attacks as attackers employ
various obfuscation techniques to disguise malicious SQL payloads. This study proposes a
detection method for SQL injection attacks based on AST-LSTM.
(1) In response to the challenge of accurately detecting SQL injection attacks on web ser-
vice servers, traditional methods primarily rely on rule matching. This approach is heavily
dependent on manual expertise and requires continuous updates to the rule base. This paper
proposes a method for detecting SQL injection intrusions based on an AST-LSTM framework.
Initially, the paper focuses on analyzing HTTP requests of web applications, as attackers typi-
cally inject malicious SQL payloads into various components of these requests, such as URLs
and Cookies. For this purpose, injectable parts of the HTTP requests, such as URLs and Cook-
ies, are extracted and concatenated to form a complete textual sequence for further analysis.
Subsequently, the text sequence undergoes normalization to mitigate the effects of obfuscation
techniques employed by attackers. Moreover, to address limitations in the granularity of SQL
query statement detection in existing research, this study first performs lexical and syntactic
analysis on the normalized SQL statements to generate an Abstract Syntax Tree (AST). Based
on the hierarchical structure of the AST, structural and semantic features are extracted for anal-
ysis. The LSTM deep learning model is then employed to train on the sequences generated
from the AST, demonstrating effective performance in scenarios where rule base matching fails
to keep pace with increasing data volumes. Additionally, this paper constructs a Tree-LSTM
model for SQL injection intrusion detection and evaluates it in comparison with the experiments
conducted in this study.
(2) In addressing the issue of enhancing the robustness of SQL injection attack detection
models, traditional methods utilize existing datasets from the internet for deep learning train-
ing. However, as attackers continually upgrade their obfuscation tactics, these datasets fail to
cover most attack behaviors. This paper explores the direction of using reinforcement learning
techniques to generate adversarial samples to enhance the robustness of SQL injection attack

detection models. By examining the impact of SQL injection attacks on models and employ-
ing predefined obfuscation strategies, this approach combines various obfuscation strategies to
create adversarial samples capable of bypassing SQL injection attack detection models, lead-
ing to erroneous predictions of such malicious samples. This paper proposes a reinforcement
learning-based method for generating adversarial samples. By engaging in continuous obfus-
cation of samples and confronting the target detection model, highly obfuscated adversarial
samples are generated. These adversarial samples are then used to perform adversarial training
on the detection model to increase its resistance to complex attack techniques.
(3) To facilitate practical implementation, this paper presents an AST-LSTM-based SQL
injection intrusion detection system. This system is designed to detect SQL injection attacks at
the Web server and database levels. Experiments are conducted in a controlled environment,
setting up simulated attack scenarios and capturing traffic data using packet capture tools. Ad-
ditionally, the paper utilizes search and analysis engines to store and analyze traffic data and
employs a visualization interface to display detailed traffic information and intrusion detection
results. Through extensive experiments and evaluations, the effectiveness and robustness of the
proposed SQL injection attack detection method are demonstrated, highlighting its potential in
enhancing the security of Web applications and databases.

1.2
研究意义
鉴于前述研究背景，值得注意的是，SQL 注入攻击仍然在安全领域中占据显著的地
位。这类攻击具有广泛的威胁，可能导致诸多问题，如数据库信息泄露、恶意操作、服
务器植入等，影响不容小觑。因此，亟需探寻有效途径来应对这一潜在风险。当前，攻
击者在尝试规避传统的异常流量检测方法时，采取了多种策略，包括编码、复写和内联
注释等。这些策略旨在绕过基于规则匹配和黑白名单机制的防护机制。为此，入侵检测
系统(IDS) 和Web 应用程序防火墙(WAF) 采用了多样化的手段，如正则表达式、脚本
语言，甚至是扩展的Backus-Naur 形式，以期匹配预定义的规则和签名。此外，通过对

1.3.1
SQL 注入检测研究现状
SQL 注入漏洞，作为网络安全领域中最为常见的隐患之一，从最早被提出到至今已
有20 余年的历史，一直以来都牢牢地牵动着网络安全从业人员的关注。这种潜在的漏

采取综合性的防御策略至关重要。从数据库管理到网络应用的编码，从服务器端的防火
墙到前端的输入验证，每个环节都需要严密的关注，以防止攻击者利用SQL 注入的漏
洞入侵。本节对现有的SQL 注入攻击检测方式进行总结和叙述。

1.3.2
AST 抽象语法树研究
抽象语法树（AST）是一种以树状结构表示源代码的抽象语法结构，树上的每个节
点代表一种源代码结构。这个抽象表示将JavaScript 代码进行结构化转换，以便进一步
处理。AST 广泛应用于编辑器功能，如错误提示、代码格式化、高亮显示和自动补全。
此外，工具如ESLint 和Prettier 用于检查代码错误和风格规范，而Webpack 则通过Babel
将JavaScript 语法转译。抽象树在源代码分析中具有广泛应用，每个节点表示源代码中
的不同结构。
为了将源代码的语法和词汇信息构建成语法树，张健等人[16] 提出了ASTNN，这是
一种基于AST 的神经网络。与传统模型不同，ASTNN 将大型AST 分解为小语句树，并
对语句进行编码。然后，它使用双向RNN 模型来捕捉语句的特征，最终生成代码片段
的向量表示。在安全领域，抽象树也具备潜在的应用价值。王文汉等人[17] 开发了流增
强抽象语法树（FA-AST），通过原始AST 的控制流和数据流来构建FA-AST。接着，他
们利用两种不同类型的图神经网络（GNN）来衡量代码对的相似性，用于比较源代码之
间的差异。Fabian Yamaguchi[18] 则将AST 应用于源代码审计，以便发现函数漏洞。他们
的方法从代码中提取抽象语法树，识别结构模式，将每个函数描述为这些模式的组合，
从而拆解已知漏洞并将其推断到代码库中，以便分析可能受到相同缺陷影响的函数。此
外，抽象树还可用于数据库请求语句的词法和语法分析。卓志等人[19] 将AST 应用于
SQL 注入检测，提出了一种基于长短期记忆和AST 的检测方法，可用于检测SQL 注入
攻击，即使在SQL 检测绕过场景下也能有效工作。深度学习技术充分利用了上下文和
语法信息，这为这些应用提供了更为强大的基础。

2.1.3
SQL 注入攻击成因
2.1.2 节对常见典型的SQL 注入攻击手段进行了介绍，随着攻击手法的不断迭代，
攻击者在原有典型手法上不断创新以绕过防御，但SQL 注入攻击的形成原因并未发生
本质的差别。本节从服务端、数据库端俩方面分析SQL 注入攻击的成因。
（1）未对用户输入过滤：SQL 注入攻击本质上还是由于攻击者进行了恶意的语句输
入，那么服务端未对用户输入进行过滤，就直接进行动态拼接代入数据库去执行，导致
SQL 注入攻击的产生。因此对用户输入内容以及用户的输入长度都需要进一步进行检
测。
（2）数据库信息回显：根据前面介绍的注入方法，往往数据库信息会因为注入攻击
手段，在页面上进行回显，但是Web 服务可以将数据库报错信息进行关闭，不让数据库
信息在页面中进行回显。
（3）数据库配置不当：开发人员在为Web 服务新建一个数据库时，通常需要创建一
个root 用户具有管理员权限，而管理员权限可以在数据库上执行许多与Web 应用无关
的操作，这会有很大的安全隐患，可以导致网站被挂马。所以要对数据库实施访问控制
策略，避免弱口令远程连接数据库等等。另外可以对数据库内数据内容进行加密处理保
护数据隐私。

2.2
代码表征概述
在计算机科学中，代码表征是分析和处理程序代码的基础，尤其在程序理解、代码
生成、以及安全漏洞检测等领域中具有广泛应用。同时深度学习技术已经与传统的代码
表征方法结合，以增强代码分析的能力，提高软件开发和维护的效率及安全性。以下详
细介绍了几种主要的代码表征类型，以及它们如何与深度学习技术相结合：
（1）词法和语法表征：词法和语法表征是基础代码表征方法，涉及将源代码文本转
换为词法单元（tokens）和构建抽象语法树（AST）。创建如抽象语法树（AST）这样的
结构可以直接用于深度学习模型。通过将AST 转化为向量表示，例如使用树形结构的
递归神经网络（Tree-RNNs）或基于树的卷积神经网络（Tree-CNNs），深度学习模型能
够学习和理解代码的结构特征和语法规则。这种方法被广泛应用于代码生成、自动编程
以及代码缺陷识别等任务。
（2）符号执行和语义表征：符号执行生成的执行路径和程序依赖图为深度学习模型
提供了丰富的上下文信息，有助于模型更准确地预测程序行为和潜在的安全漏洞。结合
图神经网络（GNN），深度学习可以有效处理控制流图（CFG）和数据流图（DFG）中
的复杂结构，通过学习图中节点和边的关系来预测程序行为和检测安全漏洞。
（3）特征向量和代码嵌入：特征向量的构建通常涉及手工选择的特征，而深度学习
可以自动从大量代码数据中学习特征表示。代码嵌入技术，特别是使用深度神经网络如
Word2Vec、卷积神经网络（CNN）和循环神经网络（RNN）的方法，能够自动从代码文
本中提取并学习高级语义和语法特征。这些高维向量表示对于代码推荐系统、自然语言
处理中的代码理解和语义搜索等应用非常有效。
（4）图形表征：通过将代码的图形表征与图神经网络（GNN）结合，可以极大地提
升模型处理代码结构和关系的能力。GNN 模型能够通过迭代消息传递机制学习节点间
复杂的依赖关系，从而有效地处理函数调用关系、类继承结构等复杂代码模式。这种方
法尤其适用于进行高级的代码相似性分析、结构化的代码搜索以及代码克隆检测。
通过将这些深度学习技术与传统的代码表征方法结合，能够更有效地解决软件工程
中的多样化挑战，如自动化测试、安全审计和代码维护等，同时提高软件系统的可靠性
和性能。深度学习不仅扩展了代码表征的能力，还提供了新的途径来理解和操作复杂的
程序结构和数据。

循环神经网络
RNN：循环神经网络（Recurrent Neural Network）[24] 是一类在深度学习领域广泛应
用的神经网络模型，特别适用于处理序列数据，如文本、时间序列和语音信号等。与传
统神经网络不同，RNN 具有一种独特的结构，使其能够在处理序列数据时保留并利用
先前的信息。因此RNN 模型也经常被应用于SQL 注入入侵检测[25] [26] 并且检测结果也
优于基于规则的方法。
RNN 的核心组成部分是循环单元（recurrent unit），它具有隐藏状态（hidden state）
用于存储和传递信息。在每个时间步，RNN 接收当前时间步的输入和前一个时间步的
隐藏状态，然后生成一个输出和一个新的隐藏状态。这个隐藏状态可以看作是网络在之
前时间步中学到的信息的累积，因此可以捕捉到序列中的长期依赖关系。

2.5
强化学习
强化学习是一种机器学习方法，通过智能体与环境的交互来学习如何做出决策以实
现特定目标。与其他机器学习方法不同，它不需要大量标记的数据，而是依赖奖励信号
和试错来学习最佳策略，因此具有广泛的应用领域，如自动驾驶、游戏策略、金融交易
和机器人控制。Fabio 等人[30] 部署强化学习采用一种更通用的策略用来对抗问题生成器
随机实例化的任何系统的SQL 注入攻击。Del 等人[31] 比较了两种强化代理：一种是依
赖于重要先验知识并使用高级操作的简单结构化代理；另一种是具有有限先验知识并生
成SQL 语句的无结构代理。Amouei 等人[32] 结合自适应搜索算法使用强化学习技术发
现绕过攻击模式。
在强化学习中，智能体根据当前环境状态采取行动，并根据行动的结果获得奖励或
惩罚。其目标是通过最大化累积奖励来学习一个优化策略，智能体与环境的交互过程如

些观察选择适当的行动。
2、环境（Environment）：环境是代理所操作的外部系统，它包括代理所需的一切信
息和条件。代理与环境互动，根据其行动获得反馈。环境的状态可能是可见的或不可见
的，代理需要从环境中获取信息来做出决策，可以用状态密度函数来表示：

表示为U，定义为：

句，以便更好地理解抽象语法树。代码表征是指将SQL 语句转换成计算机能够理解和
处理的形式，通常包括词法分析和语法分析两个步骤。词法分析将SQL 语句分解成一
个个的词法单元，如关键字、标识符、运算符等，而语法分析则将词法单元组合成语法
结构，形成抽象语法树。抽象语法树是SQL 语句的一种抽象表示形式，可以帮助更好
地理解和分析SQL 语句的结构和含义，为后续的研究工作提供基础。
随后，本章节将介绍循环神经网络和强化学习算法等内容，这些内容对于本课题中
SQL 注入入侵检测方法的设计和实现具有重要意义。循环神经网络是一种特殊的神经
网络结构，具有记忆能力，适合处理序列数据，如文本、时间序列等。在本研究中，将
利用循环神经网络来对SQL 语句进行建模，以便更好地识别其中的恶意代码。强化学

生成混淆样本，用于规避型对抗训练。
综上所述，通过对SQL 注入攻击、抽象语法树、循环神经网络和强化学习算法等

Tree-LSTM 模型的结构基于传统LSTM 单元进行拓展，以适应树形数据结构。在标
准的LSTM 中，模型按序列处理信息，而Tree-LSTM 则在每个节点上处理来自其子节
点的信息。这样的设计让Tree-LSTM 能够自然地应用于树形结构数据，通过递归地合
并子节点信息，最终得到树的根节点表示，这个表示包含了整棵树的信息。根据图3.2所
示，信息从叶子节点开始，通过树的分支向上流动，直到达到根节点。这种自底向上的
信息流动方式使得每个节点的最终表示都包含了它所有子树的信息。所以节点x3 和节
点x6 之间的信息关联并不需要顺序经过x4 和x5，因此语句的层次结构更易捕捉，同时
也有助于学习长距离依赖。

3.3.2
结构特征检测原理介绍
通常情况下攻击者构造的攻击载荷在树节点数量，节点类型上同正常的语句都具有
差别，王杰[39] 在进行基于抽象语法树的结构特征检测时仅对节点个数进行计算，同时
对AST 抽象语法树进行遍历给各个字符串、符号预设hash 值，最后对树节点的hash 值
进行累加运算，本文认为此方法因为一个字符的不同就会导致整个hash 值的差距过大，
同时单纯的节点个数计算不能反映抽象语法树的结构特征。本文将SQL 抽象语法树进
行遍历，裁剪掉冗余部分得到规范的语法树，例如在SQL 语句中可能存在用户名和密
码这样的敏感信息，本文将字符串用# 替代，数字用$ 替代使得抽象语法树规范化。然
后基于SQL 语法树进行结构特征提取，提取的特征包括：子树的个数t，树的高度h，节
点个数n，第一棵子树节点的个数tn…即如公式3.8所示：

本章小结
为了对WEB 服务器端的HTTP 流量进行SQL 注入攻击的异常检测，本文提出了一
种基于AST-LSTM 的入侵检测方法，因为正常的SQL 语句具有很强的结构性特征，因
此可以被解析为AST 抽象语法树，本文通过对抽象语法树的结构特征和语义特征进行
提取，分别对其进行检测以识别正常SQL 语句和异常SQL 语句的差异。首先将SQL 语
句进行归一化处理以便能够进行抽象语法树生成，并提取抽象语法树的结构特征如树的
高度、节点个数、子树个数等，将抽象语法树的结构特征通过构建知识库以便后续能够
进行检测。
之后，将通过结构检测的抽象语法树进行深度遍历实现序列化，同时训练Word2Vec
词嵌入模型来对序列进行向量化表示，利用深度学习对模型进行训练。本文将AST-
LSTM、Tree-LSTM 和未使用抽象语法树特征分析方法进行对比实验，实验结果表明
AST-LSTM 在各项数值上效果均优于未使用抽象语法树特征分析方法，同时在除精确度
之外的评价指标比Tree-LSTM 有优势，因此，本研究认为AST-LSTM 在SQL 注入攻击
检测方面具有更好的性能和效果。同时本文对嵌入维度、深度学习模型以及模型的超参
数进行修改来对比实验以找到最适模型和参数，为第四章的SQL 注入入侵检测模块提
供支持。

Q-learning 算法是一种基于值迭代的强化学习算法，用于学习在马尔科夫决策过程
（MDP）中的最佳策略[58]，它通过估计动作值函数来实现这个目标，在Q-learning 算法

5.2.1
系统设计思想
在实际工业应用中，为了保护数据库免受SQL 注入攻击的危害，一种常见的方法
是采用联合检测策略，既包括Web 服务器端的检测，也包括数据库端的检测。Web 服
务器端的检测主要旨在确保Web 应用程序不受Web 攻击威胁的影响，其中也包括SQL
注入攻击。Web 服务器端能够对用户发起的潜在恶意HTTP 请求流量进行实时监测和过
滤，还可以采取多种安全策略来应对攻击，例如封锁特定IP 地址的用户或引导潜在攻
击流量到蜜罐等安全措施。然而，Web 服务器端仅能获得HTTP 请求中包含的SQL 查
询的部分片段，而攻击者通常会对SQL 注入请求进行伪装以绕过Web 服务器端的检测。
为了进一步提高数据库的安全性，通常会在数据库端设置SQL 注入检测作为第二道防
线。数据库端的SQL 注入检测涉及到攻击者请求的完整SQL 查询，这些查询是由Web
应用程序生成的。此外，经过加密和混淆的文本通常会在Web 应用程序处理后得到还
原，因此在数据库端进行SQL 注入检测相对较为容易，同时也能够实现更高的准确性。
在本文第三章中提出一种基于AST-LSTM 的入侵检测方法，对于抽象语法树的结
构特征，通过提取抽象语法树的树高，节点个数，子树个数，叶子节点数等特征进行
hash 值的比对来对SQL 语句进行恶意性判断；之后对抽象语法树序列化利用词嵌入方
法提取SQL 语句的字符级特征，并利用LSTM 深度学习模型对数据集进行训练。最后
利用AST-LSTM 入侵检测方法来有效的对HTTP 请求中的payload 进行检测。
在本文的第四章中提出了一种基于强化学习的对抗训练方法用于生成SQL 注入攻
击样本，其中包含第三章提出的SQL 注入攻击检测模块以及对抗样本生成模块，在强
化学习中，智能体基于基础样本的状态，依据其选择的策略，从事先定义的行为空间中
挑选规则并将它们组合，以创造多样化的攻击样本。随后，这些新生成的攻击样本会被
提交给SQL 注入入侵检测模块进行严格的测试。测试的结果将用于确定奖励，根据奖
励智能体将调整其强化学习算法中的各项参数值。最终目标是采集那些成功绕过入侵检
测模块的对抗样本，以进一步分析或用于模拟攻击场景。
本文结合第三章以及第四章的研究内容，提出一种针对SQL 注入攻击的检测架构。
该框架首先借助于第四章中的SQL 注入对抗样本生成模块生成对抗样本，对第三章中
的SQL 注入检测模型进行进一步的训练以提高模型的鲁棒性，该框架利用第三章训练
完成之后的SQL 注入检测模型对所有访问Web 应用的HTTP 请求进行细致检查。需要
强调的是，整个系统在实际实施时，所有的检测模型都是离线部署的。这意味着它们只
对已发生的SQL 注入攻击进行分析，并生成相关警报，而不对SQL 注入攻击流量进行
主动拦截。这种方式有助于确保系统的高效性和可靠性。

总结
SQL 注入攻击，作为一种利用网络应用程序数据库层漏洞的恶意行为，能够让攻
击者绕过安全措施，非法访问或篡改数据库内容。该攻击手段之所以引起广泛关注，源
于其对信息安全构成的重大威胁：一旦成功，攻击者可获取敏感信息，包括但不限于个
人身份数据、认证凭证及财务记录。当前，随着云计算和大数据技术的快速发展，数据
库管理系统(DBMS) 的架构和应用场景日趋复杂化，给SQL 注入防御带来了新的挑战。
本研究提出一种基于抽象语法树的SQL 注入攻击检测方法，以期为信息安全领域提供
实用的参考和指导。
（1）本文提出一种基于AST-LSTM 的入侵检测方法，通过对SQL 这一种结构化语
言进行词法语法分析生成抽象语法树来对其进行细粒度分析，以弥补前人依赖对HTTP
流量的单一的词嵌入用于训练模型。具体的研究方法是对HTTP 流量中payload 提取并
进行归一化操作，使之成为可以进行抽象语法树解析的结构，对抽象语法树首先进行结
构特征提取，构建知识库以支持后续的结构特征检测。之后对抽象语法树进行语义特征
提取，将其深度遍历为文本序列并进行词嵌入，将词嵌入矩阵用于训练LSTM 深度学习
模型。
（2）本文结合SQL 注入入侵检测模型，提出基于强化学习的SQL 注入对抗样本生
成方法以期能更好的应对未知的SQL 注入混淆方法，同时可以解决样本不足的问题以
提高深度学习模型鲁棒性。攻击者通过各种混淆手法绕过入侵检测，本研究利用强化学
习算法A2C，设置动作空间、状态空间、奖励等来生成可以绕过入侵检测模型的混淆样
本，并将样本保存进一步用于训练SQL 注入入侵检测模型以提高模型鲁棒性。
（3）本文实现了一种SQL 注入入侵检测系统，利用Packetbeat 对网络流量进行捕
获，将捕获的流量利用SQL 注入入侵检测模型进行检测，并使用Elasticsearch 进行存储
通过Kibana 进行可视化呈现，形成一套完整的系统，方便安全人员进行进一步的研究。
6.2
展望
本文深入研究SQL 查询语句的结构化特征，利用ANTRL 来对SQL 语句生成抽象
语法树用于SQL 注入入侵检测，本研究据此提出了较为完整的研究方法以及系统模型，
本文研究依旧存在一些不足之处，以期在未来可以得到解决。

========== PAGE 87 ==========
第六章
总结与展望
（1）本文利用ANTLR 定义的树分析规则的语法描述来生成抽象语法树，其中的树
分析规则只有针对MySQL 数据库的，缺少对市面上常见的数据库如Oracle、MongoDB、
Redis 等的规则语法，因此无法对其他类型的数据库进行抽象语法树的构建，因此希望
后续可以对其他数据库类型的树分析规则进行编写。同时针对树分析规则通常针对的是
正常的SQL 查询语句，对于SQL 注入攻击的解析规则也有所缺失，对其进行补全有助
于进一步对SQL 注入攻击的类型进行分析，可以后续将SQL 注入攻击类型分为二次输
入、时间盲注、布尔盲注等攻击方式。
（2）本文利用强化学习算法A2C 生成用于对抗训练的混淆样本，将混淆样本用于
深度学习模型训练，其准确率要低于利用普通样本进行训练的模型，可以在未来在本文
研究方法的基础上对其中步骤进行优化以提高模型检测准确率，同时本文设计的SQL
注入入侵检测系统，用于实际检测需要考虑其效率，因此需要后续考虑降低模型的算法
复杂度以提高效率，同时可以考虑将传统的规则匹配方法与深度学习模型检测相互结合
提高检测准确率。
