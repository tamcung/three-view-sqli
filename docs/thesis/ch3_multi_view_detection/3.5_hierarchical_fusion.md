## 内容大纲

§1 融合层动机
  - 三视图特征异构
  - 直接 concat 丢失视图间交互
  - 分层融合: 抽象视图先互动, 表面视图后查询

§2 Stage 1 抽象视图自注意
  - 输入: [z_L, z_C] 长度 2 序列
  - 多头自注意 (n_heads=4)
  - 残差 + LayerNorm + FFN
  - 输出: abstract_seq ∈ [B, 2, d_fusion]
  - 公式 + 子图

§3 Stage 2 跨视图交叉注意
  - Query: abstract_seq
  - Key/Value: H_BPE（投影后）
  - 多头交叉注意 + 残差 + LN + FFN
  - 输出: attended_seq ∈ [B, 2, d_fusion]
  - 公式

§4 最终特征聚合与分类头
  - z_LA = abstract_seq.mean()
  - z_final = attended_seq.mean()
  - cls_input = concat([z_LA, z_final])
  - 分类头: Linear → GELU → Dropout → Linear → 1 logit

§5 训练辅助: 视图 Dropout 与辅助监督
  - 训练时按概率 p=0.1 随机置零某视图
  - 三个辅助分类头
  - 损失加权 (0.7, 0.1, 0.1, 0.1)
