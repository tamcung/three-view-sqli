## 内容大纲

§1 总体推理流程伪代码
  Algorithm 3.1: MultiViewSQLi-Detection(payload)
    Input: 用户输入 payload
    Output: attack / benign
    1. bpe_ids ← BPETokenizer(payload)
    2. char_ids ← ByteTokenizer(payload)
    3. lex_ids ← LibinjectionTokenizer(payload)
    4. z_BPE, H_BPE ← BPEEncoder(bpe_ids)
    5. z_C ← CharCNN(char_ids)
    6. z_L ← LexEncoder(lex_ids)
    7. abstract_seq ← Stage1SelfAttn([z_L, z_C])
    8. attended_seq ← Stage2CrossAttn(abstract_seq, H_BPE)
    9. z_final ← concat(abstract_seq.mean, attended_seq.mean)
    10. logit ← Classifier(z_final)
    11. return sigmoid(logit) > 0.5
