## 内容大纲

§1 三视图分工原理
  | 视图 | 表征单元 | 词表 | 捕获特征 |
  - BPE 子词: CodeBERT tokenizer, 词表 50265, 自然词级模式
  - 字节级: utf-8 byte, 词表 257, 编码混淆痕迹
  - 词法 Token: libinjection type code, 词表 24, 注入语法指纹

§2 BPE 子词表征构建
  - 用预训练 CodeBERT tokenizer
  - 截断至 max_len=257（含 CLS）
  - PAD id=1
  - 例子 payload 的 BPE 化结果

§3 字节级字符表征构建
  - 每个 utf-8 字节 → ID ∈ [1, 256]
  - PAD id=0
  - 例子 payload 的字节序列

§4 词法 Token 表征构建
  - libinjection tokenize（FLAG_QUOTE_NONE | FLAG_SQL_MYSQL）
  - 24 类 type code（s/n/1/k/...）
  - 注释 token 丢弃
  - 例子 payload 的 type code 序列
