## 内容大纲

§1 第三章模型的鲁棒性现实（~半页）
  - clean test F1 = 0.9991, 在 §3 数据集上几乎完美
  - 但持出对抗集 (146 样本) recall = 0.7%（1/146）
  - 模型对未见混淆变形几乎全军覆没

§2 对抗鲁棒性的工程意义（~半页）
  - WAF 实际部署中攻击者会主动绕过
  - 仅靠 §3 的 tamper 增强不足以覆盖 OOD 攻击
  - 需要专门的对抗训练机制

§3 现有对抗训练方法的局限（~1 页）
  - 简单数据增强：可能损害 clean 精度
  - 单层防御：仅在数据层（生成对抗样本）或仅在嵌入层
  - 缺乏迭代机制：模型修复一类攻击后无法应对新攻击

§4 本章解决思路（Hu 风格 wrap-up，1 段）
  '本章针对上述瓶颈，提出基于变异攻击与嵌入扰动的双层协同进化对抗训练方法。
  具体而言：① 设计一组保语义的变异算子，通过迭代爬山搜索生成对抗样本（§4.3）；
  ② 引入 FreeLB 嵌入空间 PGD 扰动作为训练内层防御（§4.4）；
  ③ 通过协同进化迭代框架将攻击-训练串联，多轮逐步提升鲁棒性（§4.5）。'
