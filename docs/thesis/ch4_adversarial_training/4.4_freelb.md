## 内容大纲

§1 嵌入空间对抗的动机（~半页）
  - 文本对抗的离散性：直接在 token 上做 PGD 不可行
  - 解决思路：在词嵌入连续空间施加扰动
  - FreeLB（Zhu et al. 2020 ICLR）的核心思想

§2 min-max 鲁棒优化形式化（~半页）
  原始训练: min_θ E_{(x,y)} L(f_θ(x), y)
  对抗训练: min_θ E_{(x,y)} max_{||δ|| ≤ ε} L(f_θ(emb(x) + δ), y)
  - 内层 max: 找最坏扰动 δ
  - 外层 min: 训练模型抵抗扰动

§3 K 步 PGD 内层求解（~1 页）
  - 初始化 δ_0 ~ Uniform(-σ, σ)
  - for k = 1..K:
    1. 前向: out = f(emb(x) + δ_{k-1})
    2. 计算 ∂L/∂δ_{k-1}
    3. δ_k = clip(δ_{k-1} + α · sign(∇), -ε, +ε)
  - δ_K 即为内层 max 的近似解
  - 公式 + 一张子图

§4 梯度累积技巧（~半页）
  - 每步 PGD 都做一次完整前向+反向
  - 各步对模型参数的梯度累加（除 K+1 缩放）
  - 一次 optimizer.step() 即可更新参数
  - 'Free' 来源：与传统多 epoch PGD 对比省下重复前向

§5 应用到 BPE 词嵌入（~1 页）
  - 仅对 BPE 词嵌入施加扰动（字符级 / 词法级不扰动）
  - 理由：BPE 是连续语义最丰富的表征层
  - 形状: emb ∈ [B, T, d_BPE]
  - 攻击边界：每 token 范数 ≤ ε，pad 位置不扰动
  - Algorithm 4.2 伪代码:
    1. emb_clean = BPEEmbed(input_ids)
    2. δ ← uniform(-σ, σ), masked
    3. for k = 1..K:
    4.   loss_k = L(model(emb + δ), y) / (K+1)
    5.   loss_k.backward()
    6.   δ ← clip(δ + α · normalize(grad), -ε, ε)
    7. optimizer.step()

§6 超参数（~半页）
  - K=3 步, σ=0.05, α=0.01, ε=0.2
  - 与 cotrain 外层耦合：每个 batch 内独立 PGD
