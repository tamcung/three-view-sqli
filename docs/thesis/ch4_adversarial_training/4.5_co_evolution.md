## 内容大纲

§1 协同进化的动机（~半页）
  - 单轮训练只能修复一类攻击
  - 模型修复后，攻击者可能找到新弱点
  - 通过多轮 attack-retrain 让模型对持续演化的攻击保持鲁棒
  - 攻防双方互为对手，共同进化

§2 协同进化动力学（~1 页）
  Round 0: f_0 = §3 的 tri_view_stage_aug 模型
  Round r (r=1..R):
    1. 攻击侧: 用 §4.3 的算法 4.1 攻击 f_{r-1}
       - 种子: 训练集中模型高置信攻击样本
       - 输出: D_adv^r 对抗样本集
    2. 训练侧:
       - 训练数据: D_train ∪ (D_adv^1 ∪ ... ∪ D_adv^r)  # 累积
       - 用 §4.4 的 FreeLB 训练 E 个 epoch
       - 输出: 更鲁棒模型 f_r
    3. 评估: f_r 在持出对抗集上的 recall

§3 训练数据合并策略（~半页）
  - 累积式 vs 替换式: 我们采用累积
  - 理由: 防止模型遗忘前轮鲁棒性
  - 数据规模: D_train (~51k) + Σ D_adv^r (~50-150)

§4 算法 4.3 伪代码（~半页）
  Input: 初始模型 f_0, 训练集 D_train, 持出对抗集 D_holdout, 轮数 R
  Output: 鲁棒模型 f_R
  1. for r = 1..R:
  2.   D_adv^r = ∅
  3.   for 种子 p in select_seeds(D_train):
  4.     p* = MutationAttack(p, f_{r-1})  # 算法 4.1
  5.     if f_{r-1}(p*) < 0.5: D_adv^r ∪= {p*}
  6.   D_r = D_train ∪ (D_adv^1 ∪ ... ∪ D_adv^r)
  7.   f_r = TrainWithFreeLB(f_{r-1}, D_r, E epochs)  # 算法 4.2
  8.   报告 f_r 在 D_holdout 上的 recall
  9. return f_R

§5 终止条件与轮数选择（~半页）
  - 固定轮数 R=3（实验充足）
  - 早停: 若持出对抗 recall 饱和（>0.99）可停
  - 学习率衰减: 每轮 lr=1e-4，warmup-cosine
