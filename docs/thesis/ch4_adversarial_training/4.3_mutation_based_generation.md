## 内容大纲

§1 整体思路（~半页）
  - 通过保语义语法变换生成对抗样本
  - 每步选择最大降低模型置信度的变换
  - 直至模型误判为良性

§2 变异算子设计（~1.5 页）
  9 个保语义算子（按家族组织）：
  - 注释/空白家族:
    1. 注释空白替换（空格 ↔ /**/ 互换）
    2. 空白字符多样化（空格 → \t \n \f \v）
    3. 注释内容重写（/*xxx*/ → /*yyy*/）
    4. 行内注释规范化（/*xxx*/ → /**/）
  - 关键字/运算符家族:
    5. 关键字大小写随机化（SELECT → sElEcT）
    6. 等价运算符替换（OR ↔ ||, = ↔ LIKE）
  - 表达式家族:
    7. 整数表达式替换（1 → (SELECT 1) 或十六进制）
    8. 恒真式重写（1=1 → 'a'='a' 或 2=2）
    9. 逻辑不变式插入（X → X AND True / X OR False）
  - 强调：所有算子保留 SQL 语法合法性，无需后置验证
  - 配 1 个完整变换示例：原 payload → 各算子作用结果

§3 贪心爬山搜索算法（~1 页，关键算法节）
  - Algorithm 4.1 伪代码:
    Input: 种子 payload p_0, 检测模型 f, 阈值 τ
    Output: 对抗 payload p*
    1. p ← p_0
    2. for r = 1..R_max:
    3.   生成 K 个候选: c_k = apply(随机算子, p), k=1..K
    4.   计算 score_k = f(c_k)
    5.   c* = argmin_k score_k
    6.   if score(c*) < score(p): p ← c*
    7.   if f(p) < τ: return p   # 攻击成功
    8. return p

  - 参数: K=24（每轮候选数）, R_max=50（最大轮数）
  - 早停条件：连续若干轮无改进

§4 攻击成功判定（~半页）
  - 单判据：模型预测概率 < 0.5
  - 不需要后置语义验证（算子设计保证合法性）
  - 边界处理：跳过空字符串、与原始相同的变换

§5 算法应用流程（~半页）
  - 种子选择：训练集中模型高置信攻击样本
  - 对每个种子独立运行 Algorithm 4.1
  - 成功样本去重后纳入对抗样本池
  - 用于 §4.5 的协同进化训练
